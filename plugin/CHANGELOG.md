# VolumeGuard Limiter — изменения

## 1.4.0

- **Lookahead 1…10 мс** (новый параметр, по умолчанию 5 мс, как раньше). Меньше — меньше задержка, например для
  мониторинга в Elgato Wave Link (при 1 мс плагин задерживает звук на ≈ 1,2 мс вместо 5,2); больше — мягче звук
  на басах и взрывах. Потолок держится при любом значении. Смена — без щелчка: короткое затухание, переключение
  и нарастание; задержка сразу сообщается программе-хосту. Параметр не автоматизируется.
- **Установщик** `VolumeGuardLimiter-Setup.exe`: сам кладёт VST3 и CLAP в `C:\Program Files\Common Files\`,
  можно выбрать форматы, обновляется поверх, удаляется из «Приложений». Архив для ручной установки остаётся.
- Окно стало выше (520×600): ползунок Lookahead в блоке настроек.
- Проверки: lookahead от 1 до 10 мс при 44,1 / 48 / 96 кГц (потолок, задержка, смена без щелчка);
  установщик на каждой сборке ставится на Windows без вопросов, проходит pluginval и чисто удаляется.

## 1.3.0

- **Шаги слышнее в Tactical.** Игровой режим делит звук на три полосы (150 Гц и 2 кГц). В верхней полосе тихие
  звуки поднимаются: в Tactical ≈ +7 дБ при Amount 50 % (до +12 дБ), в Comfort немного; тише −72 дБ — нет.
- **Auto Release** (новый параметр, включён): после одиночного пика возврат вдвое быстрее Release,
  при долгом ограничении — до 3 раз медленнее, без «качания».
- **True Peak** (новый параметр, включён): ограничение пиков между сэмплами, 4× интерполяция.
  Задержка 247 сэмплов при 48 кГц вместо 239.
- **Пресеты** Default / Shooter / Movie / Night — кнопками в окне и в списке пресетов программы-хоста.
- **График ослабления** за последние 10 секунд под индикаторами. Окно стало выше (520×560).

## 1.2.1

- **Без щелчков при смене настроек.** Input Gain, режим (Limiter / Comfort / Tactical) и Amount меняются плавно,
  за ~20 мс; Bypass включается и выключается плавным переходом между обработанным и исходным звуком.
- **Ceiling можно опускать на ходу.** Раньше звук, уже набранный в 5-миллисекундный буфер, на это время жёстко
  обрезался по новому потолку — короткий щелчок. Теперь каждый сэмпл ограничивается тем потолком, по которому
  для него была рассчитана громкость, а новый потолок вступает через 5 мс.
- Счётчик срабатываний страховочного ограничения; тесты проверяют, что оно не срабатывает ни разу.

## 1.2.0

- Игровой режим: **Comfort** (без резких скачков) и **Tactical** (тише выстрелы, взрывы и гул машин,
  громче шаги). Двухполосный компрессор с кроссовером Линквица — Райли на 150 Гц, подъём общего уровня,
  лимитер на выходе. Направление звуков не меняется.
- Новые параметры **Mode** и **Amount**, кнопки режимов в окне плагина.
- Input Gain теперь применяется до игрового режима; в режиме Limiter звук такой же, как раньше.

## 1.1.1

- Исправлено: программа-хост могла падать при нажатии кнопки BYPASS в окне плагина. Bypass был связан
  со специальным параметром отключения VST3, которым управляет сам хост; теперь это обычный параметр плагина.
  Отключать плагин средствами самой программы (её кнопкой) по-прежнему можно.
- Плагин аккуратно пропускает пустые блоки звука, которые некоторые хосты присылают при паузе.

## 1.1.0

- У плагина появилось своё окно: ползунки Input Gain, Ceiling и Release, переключатель Bypass,
  индикаторы уровня на входе и выходе и индикатор ослабления. Раньше некоторые программы (например,
  FL Studio) показывали вместо него пустое окошко.
- Индикаторы плавно спадают (20 дБ в секунду), чтобы их было удобно читать.

## 1.0.0

Первая версия: лимитер с упреждением 5 мс, параметры Input Gain, Ceiling, Release, Bypass
и индикатор Gain Reduction. Форматы VST3 и CLAP для Windows.
